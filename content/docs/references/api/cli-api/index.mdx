## Installation

`@wvb/cli/api` is an export subpath of `@wvb/cli`. Use the package name when installing it.

Node.js version requirement: `^20.19.0 || >= 22.12.0`.

Add the package to your project's development dependencies:

<Tabs items={['npm', 'pnpm', 'yarn']}>
  <Tab value="npm">

```sh
npm install -D @wvb/cli
```

  </Tab>
  <Tab value="pnpm">

```sh
pnpm add -D @wvb/cli
```

  </Tab>
  <Tab value="yarn">

```sh
yarn add -D @wvb/cli
```

  </Tab>
</Tabs>
