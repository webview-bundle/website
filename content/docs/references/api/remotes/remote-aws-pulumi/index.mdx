## Installation

`@wvb/remote-aws/pulumi` is an export subpath of `@wvb/remote-aws`. Use the package name when installing it.

Node.js version requirement: `>=22`.

Add the package to your project's dependencies:

<Tabs items={['npm', 'pnpm', 'yarn']}>
  <Tab value="npm">

```sh
npm install @wvb/remote-aws
```

  </Tab>
  <Tab value="pnpm">

```sh
pnpm add @wvb/remote-aws
```

  </Tab>
  <Tab value="yarn">

```sh
yarn add @wvb/remote-aws
```

  </Tab>
</Tabs>
