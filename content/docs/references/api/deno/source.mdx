The local bundle store: read-only builtin bundles shipped with the app, plus a writable directory
of downloaded remote ones. A remote version takes priority over the builtin of the same name.

Owns a native handle — call `Source.free` (or `using source = new Source(...)`) when done.

[View source ↗](https://github.com/webview-bundle/webview-bundle/blob/35b5cd4896c272f05103799a4bb66211ee104804/packages/deno/lib/source.ts#L86)
