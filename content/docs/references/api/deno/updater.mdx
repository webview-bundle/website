Drives the update cycle over a [`Source`](/docs/references/api/deno/source) and a [`Remote`](/docs/references/api/deno/remote): ask what is available,
download it, then install (or roll back) what was downloaded.

Owns a native handle — call `Updater.free` (or `using updater = new Updater(...)`) when done.
