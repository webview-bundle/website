A `.wvb` bundle loaded into memory: its header, index and every entry's (compressed) data. Use it
to read multiple entries without re-parsing, or as the input to [`writeBundle`](/docs/references/api/deno/write-bundle). Owns a native
handle — call `Bundle.free` (or `using bundle = ...`) when done.
