## 설치

`@wvb/deno/install`은 `@wvb/deno` 패키지의 하위 경로입니다. 설치할 때는 패키지 이름을 사용하세요.

프로젝트에 JSR 패키지를 추가하세요:

```sh
deno add jsr:@wvb/deno
```

실행할 플랫폼의 네이티브 라이브러리를 다운로드하세요:

```sh
deno run --allow-net --allow-read --allow-write @wvb/deno/install
```

라이브러리는 `.wvb/lib`에 저장됩니다. 실행 권한과 패키징 설정은 [Deno Desktop 가이드](/docs/guide/deno-desktop)를 참고하세요.
