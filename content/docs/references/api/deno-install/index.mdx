## Installation

`@wvb/deno/install` is an export subpath of `@wvb/deno`. Use the package name when installing it.

Add the JSR package to your project:

```sh
deno add jsr:@wvb/deno
```

Download the native library for the platform you run on:

```sh
deno run --allow-net --allow-read --allow-write @wvb/deno/install
```

The library is saved under `.wvb/lib`. For runtime permissions and packaging, see the [Deno Desktop guide](/docs/guide/deno-desktop).
