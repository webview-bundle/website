The command for creating a project is:

```sh
yarn create wvb
```

The planned workflow lets you choose a project directory and a template. The
prompts and generated run scripts will be finalized when the CLI is implemented.

### Templates

| Template           | Purpose                                     |
| ------------------ | ------------------------------------------- |
| `electron`         | Standard Electron app                       |
| `electron-forge`   | Electron app packaged with Forge            |
| `electron-builder` | Electron app packaged with electron-builder |
| `tauri`            | Tauri app (v2)                              |
| `android`          | Kotlin app using Android WebView            |
| `ios`              | Swift app using WKWebView                   |
| `deno-desktop`     | Deno Desktop app (experimental)             |
