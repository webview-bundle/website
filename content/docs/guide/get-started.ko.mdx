---
title: '시작하기'
---

새로운 프로젝트 생성에 사용할 명령은 다음과 같습니다:

<Tabs items={['npm', 'yarn', 'pnpm']}>
  <Tab value="npm">
    ```sh
    npm create wvb@latest
    ```
  </Tab>
  <Tab value="yarn">
    ```sh
    yarn create wvb
    ```
  </Tab>
  <Tab value="pnpm">
    ```sh
    pnpm create wvb
    ```
  </Tab>
</Tabs>

프로젝트 디렉터리와 템플릿을 선택하는 흐름을 예정하고 있습니다. 실제 질문 항목과
생성되는 실행 스크립트는 CLI 구현 후 확정합니다.

### 템플릿

| 템플릿             | 용도                                      |
| ------------------ | ----------------------------------------- |
| `electron`         | 일반 Electron 앱                          |
| `electron-forge`   | Forge로 패키징하는 Electron 앱            |
| `electron-builder` | electron-builder로 패키징하는 Electron 앱 |
| `tauri`            | Tauri 앱 (v2)                             |
| `android`          | Android WebView를 사용하는 Kotlin 앱      |
| `ios`              | WKWebView를 사용하는 Swift 앱             |
| `deno-desktop`     | Deno Desktop 앱 (실험적)                  |
