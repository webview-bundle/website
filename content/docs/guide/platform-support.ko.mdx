네이티브 플랫폼을 선택할 때 통합 패키지가 요구하는 최소 버전을 확인하세요.

## 플랫폼 지원 버전

각 통합의 요구사항은 다음과 같습니다:

| 통합                                     | 최소 요구사항                                            | 비고        |
| ---------------------------------------- | -------------------------------------------------------- | ----------- |
| [Electron](/docs/guide/electron)         | Electron 15                                              |             |
| [Tauri](/docs/guide/tauri)               | Tauri 2, MSRV 1.90                                       |             |
| [Android](/docs/guide/android)           | Android 7.0, API 24                                      |             |
| [iOS](/docs/guide/ios)                   | iOS 16                                                   |             |
| [Deno Desktop](/docs/guide/deno-desktop) | `desktop` 명령과 `deno.desktop` 타입을 제공하는 Deno 2.9 | 실험적 지원 |
