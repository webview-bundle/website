title: 'Platform support'
---

When choosing a native platform, check the minimum versions required by its
integration package.

## Supported platform versions

Each integration has the following requirements:

| Integration                              | Minimum requirements                                         | Notes                |
| ---------------------------------------- | ------------------------------------------------------------ | -------------------- |
| [Electron](/docs/guide/electron)         | Electron 15                                                  |                      |
| [Tauri](/docs/guide/tauri)               | Tauri 2, minimum supported Rust version (MSRV) 1.90          |                      |
| [Android](/docs/guide/android)           | Android 7.0, API 24                                          |                      |
| [iOS](/docs/guide/ios)                   | iOS 16                                                       |                      |
| [Deno Desktop](/docs/guide/deno-desktop) | Deno 2.9 with the `desktop` command and `deno.desktop` types | Experimental support |
