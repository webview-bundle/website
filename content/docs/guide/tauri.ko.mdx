기존 Tauri 2 앱에 Rust 플러그인을 추가하고 프록시로 프론트엔드를 실행한 뒤, 빌트인 번들로 전환합니다. 데스크톱 앱을 기준으로 설명하며, 마지막에 모바일 패키징 차이를 안내합니다.

## 시작 전 준비

실행 가능한 Tauri 2 프로젝트, Rust 1.90 이상, `@wvb/cli`가 지원하는 Node.js(20.x에서는 20.19 이상, 또는 22.12 이상)를 준비하세요. 프론트엔드는 `web`에 배치합니다. 운영체제별 준비는 [Tauri 사전 준비](https://v2.tauri.app/start/prerequisites/)를 따르세요.

## 1. 의존성 설치

`src-tauri/Cargo.toml`에 의존성을 추가하세요:

```toml title="src-tauri/Cargo.toml"
[dependencies]
wvb-tauri = "0.3"
```

## 2. 플러그인 초기화와 개발 서버 연결

Tauri 빌더에 `bundle` 스킴의 프록시를 등록하세요:

```rust title="src-tauri/src/main.rs"
use wvb_tauri::{Config, ProtocolConfig, wvb::protocol::ProxyResolver};

fn main() {
  let hosts = ProxyResolver::host_mapping([
    ("app.wvb", "http://localhost:5173"),
  ]);
  tauri::Builder::default()
    .plugin(wvb_tauri::init(
      Config::new().protocol(ProtocolConfig::proxy("bundle", hosts)),
    ))
    .run(tauri::generate_context!())
    .expect("failed to run app");
}
```

`src/lib.rs`가 있는 프로젝트라면 기존 `run()`의 빌더에 플러그인 등록을 추가하세요. `tauri.conf.json`에서 메인 창의 URL을 설정하세요:

```json title="src-tauri/tauri.conf.json"
{
  "app": {
    "windows": [
      { "label": "main", "url": "bundle://app.wvb/" }
    ]
  }
}
```

이 조각을 기존 설정에 병합하세요. `http://localhost:5173`에서 프론트엔드 서버를 시작하고 Tauri 앱을 실행해 화면을 확인하세요.

## 4. 로컬 빌드 결과를 빌트인으로 설치

웹 워크스페이스의 `dist` 디렉터리를 `app` 번들, `1.0.0` 버전으로 패키징하도록 설정하세요:

```ts title="web/wvb.config.ts"
import { defineConfig } from '@wvb/cli';

export default defineConfig({
  pack: { srcDir: './dist' },
  remote: { bundleName: 'app', version: '1.0.0' },
});
```

네이티브 프로젝트 루트에서 `builtin.target`이 웹 워크스페이스를 가리키도록 설정하세요:

```ts title="wvb.config.ts"
import { defineConfig } from '@wvb/cli';

export default defineConfig({
  builtin: {
    outDir: './src-tauri/bundles',
    target: { type: 'local', workspaces: ['./web'] },
  },
});
```

프론트엔드의 기존 빌드 명령을 실행하세요. `web/dist/index.html`이 생성되면 네이티브 프로젝트 루트에서 다음 명령을 실행하세요:

```sh
yarn wvb builtin
```

CLI는 웹 빌드 결과를 패키징하고 `./src-tauri/bundles/manifest.json`과 `./src-tauri/bundles/app/1.0.0.wvb`를 생성합니다.

`tauri.conf.json`에 리소스 매핑을 추가하세요:

```json title="src-tauri/tauri.conf.json"
{
  "bundle": {
    "resources": { "bundles/": "bundles/" }
  }
}
```

## 5. 빌트인 번들 실행과 확인

프록시 호스트 매핑을 제거하고 플러그인 설정을 다음과 같이 교체하세요:

```rust title="src-tauri/src/main.rs"
use wvb_tauri::{Config, ProtocolConfig, wvb::protocol::ProxyResolver};

fn main() {
  let hosts = ProxyResolver::host_mapping([ // [!code --]
    ("app.wvb", "http://localhost:5173"),  // [!code --]
  ]); // [!code --]
  tauri::Builder::default()
    .plugin(wvb_tauri::init(
      Config::new().protocol(ProtocolConfig::proxy("bundle", hosts)), // [!code --]
      Config::new().protocol(ProtocolConfig::bundle("bundle")), // [!code ++]
    ))
    .run(tauri::generate_context!())
    .expect("failed to run app");
}
```

프론트엔드 서버를 종료하고 기존 Tauri 명령으로 네이티브 앱을 다시 빌드하세요. `bundle://app.wvb/`에서 화면이 표시되어야 합니다. 패키징한 리소스에 `bundles/manifest.json`과 `bundles/app/1.0.0.wvb`가 있어야 합니다.

## 모바일 패키징

Android 을 지원하기 위해 [tauri-plugin-fs](https://v2.tauri.app/reference/javascript/fs/)가 필요합니다. `Cargo.toml`에 해당 의존성을 추가하세요.

```toml title="src-tauri/Cargo.toml
[dependencies]
tauri-plugin-fs = "2"
```

`tauri_plugin_fs::init(){:rust}` 플러그인은 `wvb_tauri::init(){:rust}` 보다 먼저 등록돼야 합니다.

```rust title="src-tauri/src/main.rs"
use wvb_tauri::{Config, ProtocolConfig, wvb::protocol::ProxyResolver};

fn main() {
  tauri::Builder::default()
    .plugin(tauri_plugin_fs::init())
    .plugin(wvb_tauri::init(/* */))
    .run(tauri::generate_context!())
    .expect("failed to run app");
}
```
